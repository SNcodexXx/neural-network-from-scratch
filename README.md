# Neural Network from Scratch 
**Цель проекта:** реализовать основные компоненты нейронной сети на чистом NumPy без PyTorch - с собственным forward/backward pass для каждого слоя - и обучить на Kaggle MNIST.

---

## Что реализовано с нуля

Каждый компонент - отдельный класс с ручным выводом градиентов:

**Базовая архитектура**
- `Layer` - базовый класс со стандартным интерфейсом `forward` / `backward` и переключением режимов `train()` / `eval()`
- `Sequential` - контейнер, последовательно применяющий слои в forward и в обратном порядке в backward

**Функции активации**
- `ReLU`, `Sigmoid`, `Tanh` - с производными, выведенными и реализованными вручную

**Основные слои**
- `Linear` - полносвязный слой с инициализацией весов и градиентами по входу, весам и bias
- `BatchNorm` - батч-нормализация с накоплением running mean/var для инференса
- `Dropout` - регуляризация с inverted dropout 

**Функции потерь**
- `CrossEntropyLoss` - для классификации
- `MSELoss` - для регрессии

**Оптимизатор**
- `Adam` - с моментами первого и второго порядка и bias correction, обновление весов и bias по отдельности для каждого слоя

Каждый компонент протестирован отдельно до сборки в общую сеть.

---

## Архитектура сети

```
Linear(784, 512) → BatchNorm → ReLU → Dropout(0.3)
Linear(512, 256) → BatchNorm → ReLU → Dropout(0.3)
Linear(256, 128) → BatchNorm → ReLU → Dropout(0.2)
Linear(128, 10)
```

- Loss: CrossEntropyLoss
- Optimizer: Adam (lr=0.001)
- Batch size: 64
- Аугментация: случайный сдвиг изображения по осям x/y (`np.roll`) для повышения устойчивости модели

## Датасет

[Kaggle Digit Recognizer](https://www.kaggle.com/competitions/digit-recognizer) — классификация рукописных цифр 0–9, изображения 28×28 в развёрнутом виде, нормализация в диапазон [0, 1].

## Результаты

- Обучение: 45 эпох, loss стабильно снижался с ~0.30 до **0.145**
- Точность на обучающей выборке: **98.52%**
- Точность на тестовой выборке: **97%**
- Kaggle leaderboard: **0.98021** accuracy

## Зачем этот проект

Основная цель - глубже разобраться в механике нейросетей: понять, как именно распространяется градиент через каждый слой, почему Adam и BatchNorm ускоряют обучение, и как inverted dropout работает на уровне матричных операций без абстракции высокоуровневых фреймворков.
